# Art source notes

`qingming-riverside.jpg` is a faded decorative crop sourced from Wikimedia
Commons' public-domain scan of *Along the River During the Qingming Festival*.
It is used only as a low-contrast location-field atmosphere layer; application
text, controls and saved content remain code-native and unobscured.

Source file page:
`https://commons.wikimedia.org/wiki/File:Alongtheriver_QingMing.jpg`

`thousand-li-mountains.jpg` is a UI crop of Wang Ximeng's public-domain
*A Thousand Li of Rivers and Mountains* (1113). The file was obtained from
Wikimedia Commons and remains identifiable as the original blue-green landscape;
the interface only masks and fades its edges.

Source file page:
`https://commons.wikimedia.org/wiki/File:A_Thousand_Li_of_Rivers_and_Mountains_part.jpg`
