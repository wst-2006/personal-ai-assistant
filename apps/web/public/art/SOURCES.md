# Art sources

- `cold-waterfall-ink-public-domain.png` is a locally cropped, monochrome,
  transparent derivative of Wen Zhengming's *Old Trees by a Cold Waterfall*
  (LACMA 55.67.1). The source image is marked Public Domain on Wikimedia
  Commons. Only the waterfall, cliff and tree texture is retained; inscriptions,
  seals and figures are excluded from the application asset.
