# Personal AI Assistant v0.1.21

Personal AI Assistant 是一个 Windows 优先、本地运行、单用户的个人任务与成长助手。它把一天中的安排、专注执行、任务评价、每日复盘、日记、成长趋势和健康参考放在同一个工作流里，同时把最终决定权留给用户：AI 可以帮助整理和提出候选，但不会未经确认修改你的计划。

## 核心体验

### 今天：把计划放进真实的一天

- 通过上午、下午、晚上时间页和完整时间轴管理当天安排。
- 区分正式任务、未排期想法、问题、收件箱内容和当天事实补录。
- 支持拖动排期、明确开始与结束时间，并在发生冲突时要求用户确认。
- 任务结果、主观感受和复盘内容彼此独立保存。

### 专注：从准备到评价的完整闭环

- 精确任务开始前进入准备阶段，用户确认后才开始专注。
- 支持连续专注、分段专注、休息段和最终评价。
- 晚开始时，从实际开始时刻记录到原定结束时刻，不虚构开始前的时间，也不延长固定截止时间。
- 桌面专注窗口可以隐藏、置顶或固定在屏幕角落；支持多种视觉主题、通知和音效设置。
- 专注、原始计时和有效专注在复盘、日记、成长等页面使用统一的数据来源。

### AI：帮助整理，不替用户做决定

- 用自然语言整理任务、想法和问题候选。
- 从长期计划生成可编辑的任务树候选。
- 对时间冲突和计划变化提供建议，但只有用户确认后才会写入排期。
- AI 或外部服务失败时保留用户原始输入，不伪造任务或结果。

### 复盘、日记与成长

- 保存每日复盘，并可选择请求 AI 回应。
- 记录每项任务的完成情况、进度、满意度和专注时长。
- 支持将复盘与确认后的每日简报整理为可继续编辑的个人日记。
- 使用六维回看观察主线进度、执行情况、专注质量、能量、身心状态和成长收获。
- 成长页根据真实任务、专注和反馈呈现趋势、竹子阶段、任务数量对应的竹子数量和情绪痕迹，并提供中文专注名言展示。

### 健康参考

- 以周笺和日处方组织饮食、饮水、运动和安全提醒。
- AI 生成内容先作为候选，用户确认后才成为当周参考。
- 健康建议不会自动创建或修改任务。
- 支持可选的睡眠截图分析；没有可用视觉模型时会明确提示不可用。

### 数据与隐私

- API、Worker 和 PostgreSQL 均在用户自己的电脑上运行。
- DeepSeek、视觉模型和飞书凭据只保存在本地配置中，不进入前端、安装包或公开仓库。
- 支持用户主动导出的本地逻辑备份和回收站管理。
- 不包含公开注册、社交、监控、人格推断或惩罚机制。

## 下载与校验

Release 附件：

- `Personal.AI.Assistant_0.1.21_x64-setup.exe`
- `SHA256SUMS.txt`

请只从项目官方 GitHub Release 下载，并使用 `SHA256SUMS.txt` 校验安装包。当前安装包未使用商业代码签名，Windows SmartScreen 可能显示信誉提醒。

## 安装前提

- Windows 10/11 x64
- PostgreSQL 18.x
- 可选：用户自己的 DeepSeek、飞书或视觉模型账号

安装包只包含无密钥的运行文件和 `.env.example`。首次启动后，应用会在当前 Windows 用户目录创建私有配置；个人配置、API Key、数据库和本地记录不会被打入安装包或上传到 GitHub。

## 当前限制

- 电脑关闭时，本地 Worker 和飞书提醒不会继续运行。
- 当前没有云端同步、多人协作或移动端客户端。
- PostgreSQL 需要在本机单独安装和配置。
- 外部 AI、飞书和视觉能力取决于用户自己的账号、额度、网络和服务可用性。
