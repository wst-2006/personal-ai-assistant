# Personal AI Assistant v0.1.21

Personal AI Assistant 是一个 Windows 优先、本地运行的个人任务与成长助手。它把一天中的安排、专注执行、任务评价、每日复盘、日记、成长趋势和健康参考放在同一个工作流里，帮助你把计划落实为可回看的真实记录。

## 功能

### 今日计划

- 通过上午、下午、晚上时间页和完整时间轴管理当天安排。
- 区分正式任务、未排期想法、问题、收件箱内容和当天事实补录。
- 支持拖动排期、设置明确的开始与结束时间，并在发生冲突时要求确认。
- 任务结果、主观感受和复盘内容彼此独立保存。

### 专注计时

- 精确任务开始前进入准备阶段，确认后才开始专注。
- 支持连续专注、分段专注、休息段和最终评价。
- 晚开始时，从实际开始时刻记录到原定结束时刻，不虚构开始前的时间，也不延长固定截止时间。
- 桌面专注窗口可以隐藏、置顶或固定在屏幕角落，并支持多种显示和提醒设置。
- 复盘、日记和成长页面使用统一的专注时长数据。

### 复盘、日记与成长

- 保存每日复盘，记录任务完成情况、进度、满意度和专注时长。
- 支持将复盘素材整理为可继续编辑的个人日记。
- 使用六维回看观察主线进度、执行情况、专注质量、能量、身心状态和成长收获。
- 成长页根据真实任务、专注和反馈呈现趋势、竹子阶段、任务数量对应的竹子数量和情绪痕迹。

### 健康参考

- 以周笺和日处方组织饮食、饮水、运动和安全提醒。
- 建议内容先作为候选，确认后才成为当周参考。
- 健康建议不会自动创建或修改任务。
- 支持可选的睡眠截图分析；不可用时会明确提示。

### 数据控制

- 数据在本机保存，支持用户主动导出的本地逻辑备份和回收站管理。
- 安装包不包含个人记录、数据库或密钥。
- 不包含公开注册、社交、监控、人格推断或惩罚机制。

## 下载与校验

Release 附件：

- `Personal.AI.Assistant_0.1.21_x64-setup.exe`
- `SHA256SUMS.txt`

请从项目官方 GitHub Release 下载，并使用 `SHA256SUMS.txt` 校验安装包。当前安装包未使用商业代码签名，Windows SmartScreen 可能显示信誉提醒。

## 安装前提

- Windows 10/11 x64
- PostgreSQL 18.x

安装包只包含无密钥的运行文件和 `.env.example`。首次启动后，应用会在当前 Windows 用户目录创建本地配置。

## 当前限制

- 电脑关闭时，本地后台提醒不会继续运行。
- 当前没有云端同步、多人协作或移动端客户端。
- PostgreSQL 需要在本机单独安装和配置。
