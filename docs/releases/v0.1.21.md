# Personal AI Assistant v0.1.21

这是一次围绕专注计时、任务复盘和成长展示的修复版本。

## 本次更新

- 晚开始任务时，从实际开始时刻记录到原定结束时刻，不延长固定截止时间。
- 修复跨分段或 Worker 延迟时可能遗漏有效专注时长的问题。
- 飞书自然语言开始指令支持“我已经开始了这个任务”等常用表达。
- 复盘、成长和日记统一使用同一套有效专注数据，避免页面间分钟数不一致。
- “部分完成”和“完成”都计入任务完成数量，并保留各自的评分差异。
- 竹子数量根据当日任务总数动态变化：1–2 项显示 1 棵，3–4 项显示 2 棵，5 项及以上显示 4 棵。
- 任务复盘默认显示 2 项，展开后最多显示 4 项并支持滚动浏览。
- 调整复盘内部滚动衔接，列表到达边界后可继续滚动外层页面。
- 成长图景主字改为“橙”，移除旧副标题，并随机轮换中文专注名言。
- 优化专注页和桌面悬浮窗的执行、准备及结构编辑体验。

## 下载与校验

Release 附件：

- `Personal AI Assistant_0.1.21_x64-setup.exe`
- `SHA256SUMS.txt`

请只从项目官方 GitHub Release 下载，并使用 `SHA256SUMS.txt` 校验安装包。当前安装包未使用商业代码签名，Windows SmartScreen 可能显示信誉提醒。

## 安装前提

- Windows 10/11 x64
- PostgreSQL 18.x
- 可选：用户自己的 DeepSeek、飞书或视觉模型账号

已有版本可直接运行安装包覆盖升级。个人配置、API Key 和数据库不会被打入安装包或上传到 GitHub。
