# Personal AI Assistant v0.1.21

Personal AI Assistant 是一个 Windows 优先的个人任务与成长助手，把任务安排、专注执行、复盘记录和成长回看放在同一个工作流中。

## 主要功能

- **今日计划**：在时间轴上安排任务，设置开始和结束时间，查看当天的上午、下午和晚上安排。
- **专注计时**：支持准备阶段、连续专注、分段专注、休息和任务评价；晚开始时按实际开始时间记录到原定结束时间。
- **AI 协作**：用自然语言整理任务、想法和问题，生成可编辑的任务候选、计划调整建议和长期计划任务树；确认后才会写入正式安排。
- **飞书交互**：接收任务和计划信息，发送任务提醒与交互卡片；可以在飞书中确认开始任务、选择另有安排，并把消息整理回软件流程。
- **每日复盘**：记录完成情况、进度、满意度、专注时长和当天感受，可继续整理为个人日记。
- **成长回看**：根据任务、专注和反馈展示成长趋势、竹子阶段、任务数量对应的竹子数量和状态变化。
- **健康参考**：查看饮食、饮水、运动和安全提醒，并将确认后的内容作为当周参考。
- **本地数据**：任务、专注、复盘和日记保存在本机，支持本地备份与恢复管理。

## 下载

Release 附件：

- `Personal.AI.Assistant_0.1.21_x64-setup.exe`
- `SHA256SUMS.txt`

安装要求：Windows 10/11 x64、PostgreSQL 18.x。安装包不包含个人数据库或密钥；首次启动后按本机配置完成连接即可。
