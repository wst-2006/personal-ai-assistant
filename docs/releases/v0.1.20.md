# Personal AI Assistant v0.1.20

这是第一个准备公开分发的 Windows 预发布版本。它把日程、专注、复盘、成长、健康参考和 AI 候选确认整合在同一个本地优先应用中。

## 主要功能

- 上午、下午、晚上层叠时间页与完整长时间轴。
- 已排期/未排期任务分离，支持拖动排期和冲突保护。
- 一分钟准备、明确开始确认、独立专注窗口、结构化休息与可选评价。
- 五套专注计时主题和可配置窗口位置、置顶、通知及音效。
- DeepSeek 辅助的任务候选、复盘回应、健康参考和长期计划任务树。
- 飞书提醒、交互卡片及文本候选入口；任何任务创建仍需确认。
- 复盘、赛博日记、五阶段六维雷达和数据驱动成长页。
- 饮食、饮水、运动与安全信息组成的周健康参考。
- 本地逻辑备份、回收站保留策略和一键清空。

## 安装前提

- Windows 10/11 x64
- PostgreSQL 18.x
- 可选：用户自己的 DeepSeek、飞书或视觉模型账号

## 隐私说明

- 安装包不包含作者的 `.env`、API Key、飞书凭据、数据库或个人记录。
- 首次启动会在当前 Windows 用户目录创建私有配置文件。
- 外部服务全部使用用户自己的账号和密钥。
- 任务、健康内容和复盘数据保存在用户本机 PostgreSQL 中。

## 已知限制

- 电脑关闭后，本地提醒和飞书连接不会继续运行。
- PostgreSQL 需要用户单独安装和配置。
- 当前没有云同步、移动客户端或多人协作。
- Agent 联网搜索、独立每日简报和 Work Buddy 简报导入在当前版本中关闭。
- 外部服务的模型名称、额度和可用性由各服务商决定。

这是预发布版本。正式公开前仍需完成许可证选择、演示截图、私有 staging 仓库检查和最终安装验收。
