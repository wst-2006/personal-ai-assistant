# Personal AI Assistant v0.1.27

这是 Personal AI Assistant 的**首个公开版本**。它把任务安排、专注执行、复盘、成长、健康参考和可选的飞书协作连接成一套本地优先的个人工作流：从“今天准备做什么”，一直记录到“实际完成了什么、投入了多久、下一步需要怎样调整”。

本版本的重点不是增加一个单独的清单功能，而是把“计划—执行—回看”做成可恢复、可追溯、由用户最终确认的闭环。

## 已完成的核心能力

### 今天：明确安排，而不是只记标题

- 支持正式任务、想法和待处理问题分开保存。
- 支持未排期任务拖入完整时间轴，并明确设置日期、开始时间和结束时间。
- 时间轴支持上午、下午、晚上分区、当前时间提示、拖动、调整时长和键盘操作。
- 时间冲突会列出涉及的任务和时间，必须由用户明确决定是否保留，不会静默覆盖原计划。
- 任务支持取消、回收站、恢复、重新排期和版本冲突保护。
- 未排期任务支持用户选择日终顺延或移入回收站，规则由个人设置控制。

### 专注：从准备、迟到开始到评价的完整状态机

- 精确任务在开始前 1 分钟进入准备阶段；准备本身不计入专注时长。
- 用户可以确认“开始任务”、选择“另有安排”或取消任务。
- 如果倒计时结束时没有确认，系统会进入迟到开始等待，不会擅自把准备时间算成专注。
- 迟到开始只记录用户实际点击开始后的时间，并以原定结束时间作为硬截止，不会自动延长任务。
- 任务未开始到固定结束时，会记录未完成和不满意，但不会伪造专注时长，也不会错误弹出休息和评价窗口。
- 支持连续专注、分段专注、末段休息跳过，以及固定的休息规则：30 分钟为 25+5，60 分钟为 55+5，90 分钟为 80+10，120 分钟为 105+15。
- 专注窗口可以独立显示、置顶、固定位置或收起；重新打开时优先恢复当前专注任务。
- 评价窗口默认居中，支持主观感受、完成情况、满意度和历史结果记录；只有无互动满 60 秒才自动关闭，编辑和滚动都会重新计时。
- 关闭或超时后的评价仍保留在待评价列表中，可之后重新打开和修改。
- 提供水墨册页、素简翻页、辉光电子管、蒸汽波和赛博终端五套专注主题。

### 复盘、日记与成长：保留真实过程

- 每日复盘由用户保存，可选择只保存或明确请求 AI 回应。
- 复盘、软件普通对话和 AI 回复分别保存，刷新或切换页面后仍可恢复。
- 赛博日记需要用户真实提交过复盘内容，并在确认后冻结当时的任务、专注、评价和简报快照。
- 日记支持按月查看历史日期、编辑和导出文本，后续修改源任务不会偷偷重算历史快照。
- 成长页根据任务完成、专注时长和主观反馈显示趋势、状态格和竹子阶段；日、自然周、自然月等统计范围使用同一套数据库统计逻辑。

### 健康参考：给出可理解的参考，不代替用户安排

- 健康页以周笺和日参考组织饮食、饮水、运动、蔬菜、水果与补剂建议。
- AI 生成内容先进入候选，用户确认后才成为当前参考，不会自动创建训练计划或改动任务排期。
- 参考范围会解释成生活中容易理解的量，例如蛋白质对应的鸡蛋、牛肉或鸡胸肉，饮水对应的纸杯数量。
- 支持睡眠截图分析；没有可用视觉模型或凭据时会明确提示，而不是伪造结果。
- 健康对话保存到本地，可切换页面后继续回复；飞书健康消息也会归入同一周的健康交流记录。

### AI、飞书与本地优先

- AI 只负责整理候选、回答问题和给出建议；计划、任务时间和长期计划不会被 AI 静默改写。
- 任务、想法、问题、复盘和计划候选都要经过用户确认才写入对应数据。
- 飞书支持任务提醒、开始前 15 分钟提示、开始前 1 分钟确认、文字命令开始任务、另有安排和取消确认。
- 飞书任务卡片会显示任务日期、开始时间和结束时间，卡片状态与桌面专注状态保持同步。
- API、Worker、数据库和桌面运行时均按本地优先方式组织；外部 AI、视觉模型和飞书都是可选集成。

## 隐私与安全边界

- v0.1.27 是单用户应用，没有公开注册、社交、监控、人格推断或惩罚机制。
- API Key、数据库密码、飞书凭据只保存在本机私有配置中，不会进入源码、安装包或 Release 附件。
- 安装包只携带无密钥的 `.env.example`；本地数据库、日志、备份和个人记录不会随安装包发布。
- 所有外部服务是否启用由用户在本地设置中决定。

## 安装要求

- Windows 10/11 x64
- PostgreSQL 18.x（本地安装并运行）
- 可选：AI/视觉模型账号、飞书应用凭据

首次使用请先阅读：

1. [Windows 安装与数据库准备](../INSTALLATION.md)
2. [DeepSeek、飞书和视觉服务配置](../INTEGRATIONS.md)

## 已知限制

- 电脑完全关闭时，本地 Worker 不会继续运行提醒；重新启动后会进行本地状态恢复。
- AI、视觉模型和飞书提醒依赖用户自己的凭据、网络和第三方服务可用性。
- 当前没有云端同步和移动端客户端。
- Windows 安装包尚未进行商业代码签名，首次安装可能出现 SmartScreen 信誉提示。
- PostgreSQL 仍是安装包之外的本地依赖。
