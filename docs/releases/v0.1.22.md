# Personal AI Assistant v0.1.22

Personal AI Assistant 是一个帮助你安排一天、保持专注并回看实际进展的个人工作助手。

## 本次重点

- 专注任务到固定开始时间会自动开始计时；提前点击“开始任务”则从点击时刻计时到原定结束时间。
- 专注页和桌面计时窗口统一提供“开始任务 / 另有安排 / 取消任务”，点击其他任务可直接进入对应的专注时长设定。
- 重新打开专注页时优先恢复当前正在专注的任务，没有进行中的任务则回到第一个待开始任务。
- 飞书 T-15、T-1 和开始状态提示与本地计时状态保持一致。
