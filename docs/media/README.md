# Public screenshots

This directory is reserved for screenshots that are safe to publish. Capture
them from a disposable demo profile with fictional tasks, a generic location,
and empty or mocked external integrations.

Suggested filenames:

- `today-timeline.png` — stacked daypart sheets and the combined long axis;
- `focus-workflow.png` — preparation, focus, rest, and evaluation states;
- `focus-themes.png` — the five focus themes using the same `25:00` sample;
- `growth-garden.png` — bamboo growth stages, quiet feedback traces, and the
  five-stage six-dimensional radar;
- `health-reference.png` — weekly note plus food, hydration, and movement;
- `personalization.png` — theme, window position, and feature switches.

Before committing an image, check that it contains no real task title, exact
schedule, location, health note, Feishu identifier, QR code, API diagnostic,
database URL, access token, username, or local file path.
