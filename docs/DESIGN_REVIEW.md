# 视觉与交互设计评审稿

状态：待用户确认视觉方向后进入正式 UI 重构。

本稿是第一版单用户产品的设计基线。它只定义信息架构、主要流程、桌面应用框架和视觉语言，不改变 `docs/PRODUCT_SPEC.md` 中已经确认的业务规则。

## 1. 信息架构

```text
应用壳
├── 今日 / Today
│   ├── 时间轴
│   ├── 今日简报
│   └── 快速录入（任务 / 想法 / 问题）
├── 专注 / Focus
│   ├── 当前任务
│   ├── 专注计时
│   └── 结果与满意度
├── 复盘 / Review
│   ├── 完成情况
│   ├── 阻塞与反馈
│   └── 生成或编辑赛博日记
├── 成长 / Growth
│   ├── 周 / 月趋势
│   ├── 有效专注时间
│   └── 成长花园
└── 侧边层
    └── AI 助手（随时唤出，不占主画布）
```

导航只保留五个高频入口；设置、导出、连接状态和未来扩展能力放在右上角工具区或二级抽屉，避免形成密集后台菜单。

## 2. 主要用户流程

### 任务进入时间轴

```text
输入一句自然语言
  -> AI 提取候选（时间 / 时长 / 难度 / 类型）
  -> 用户确认或编辑
  -> 检查冲突
  -> 写入今日时间轴
```

表单中已经明确的任务不调用 AI。想法和问题可以直接保存为对应类型，不强制安排时间。

### 从时间轴进入专注

```text
选择任务 -> 预览计划 -> 开始专注
  -> 暂停 / 继续 / 提前结束
  -> 记录任务结果
  -> 独立记录满意度
  -> 回到今日或进入复盘
```

### 复盘到赛博日记

```text
打开复盘 -> 浏览完成 / 未完成 / 阻塞
  -> 写一条复盘消息
  -> 可选生成当日简报与日记草稿
  -> 用户编辑并确认
  -> 保存赛博日记
```

只有复盘页产生至少一条消息时，才允许创建当日赛博日记；普通 AI 对话不会自动生成日记。

## 3. 桌面端应用框架

```text
┌────────────────────────────────────────────────────────────────────┐
│ 顶栏：日期 / 当前上下文                         AI / 状态 / 设置   │
├────────────┬───────────────────────────────────────────┬───────────┤
│ 图标导航   │ 主画布                                    │ 可选侧边层 │
│ 今日       │ 当前页面的核心工作区                      │ AI 助手    │
│ 专注       │ 时间轴 / 计时器 / 复盘 / 日记               │ 草稿与建议 │
│ 复盘       │                                           │           │
│ 成长       │                                           │           │
└────────────┴───────────────────────────────────────────┴───────────┘
```

默认桌面宽度下采用窄图标轨道 + 宽主画布；AI 侧边层从右侧滑入并保留主画布上下文。窄屏时导航轨道转为底部栏，侧边层转为全高抽屉，不出现横向滚动。

## 4. 视觉方向候选

### A「夜航花园」（推荐）

深色应用壳承载“驾驶舱”感，主画布使用温和的浅色纸面；青绿色代表成长与进行中，琥珀代表提醒，珊瑚代表阻塞。适合时间轴、专注和成长反馈，也能让日记保持可读性。

### B「晨雾手账」

整体明亮、留白更大，使用墨黑、雾蓝、鼠尾草绿和少量珊瑚色。编辑感和日记气质最强，适合月视图；专注页需要额外增加状态对比度。

### C「轨道信号」

高对比深底、细线、刻度和仪表提示，强调系统感与时间精度。适合专注计时与冲突提示，但必须限制线条和信息密度，避免退化成传统后台。

本轮只实施 A，不并行开发多套主题。B、C 作为未来可替换的主题层方向保留。

## 5. Design Token 草案（A）

| 类别 | Token | 值 / 说明 |
| --- | --- | --- |
| 颜色 | `--ink-950` | `#10191A`，应用壳与主文字 |
| 颜色 | `--ink-700` | `#435556`，次要文字 |
| 颜色 | `--paper-50` | `#F7F8F4`，主画布 |
| 颜色 | `--paper-100` | `#EEF2EC`，分区背景 |
| 颜色 | `--mint-500` | `#40B89A`，成长 / 进行中 |
| 颜色 | `--amber-500` | `#E2A84A`，提醒 / 待确认 |
| 颜色 | `--coral-500` | `#D96D61`，阻塞 / 错误 |
| 字体 | `--font-ui` | Inter / system sans，界面控件 |
| 字体 | `--font-reading` | Noto Serif SC / Georgia，日记正文 |
| 间距 | `--space-1..8` | 4, 8, 12, 16, 24, 32, 40, 56 px |
| 圆角 | `--radius-sm` | 8 px，任务块与输入控件 |
| 圆角 | `--radius-lg` | 16 px，页面级工作区 |
| 阴影 | `--shadow-soft` | 0 12px 30px rgba(16,25,26,.08) |
| 动效 | `--ease-standard` | 180ms cubic-bezier(.2,.8,.2,1) |
| 动效 | `--ease-emphasis` | 320ms cubic-bezier(.16,1,.3,1) |
| 状态 | `focus-visible` | 2px mint 外描边，键盘可见 |

动效只用于页面切换、抽屉进入、计时状态和完成反馈；专注计时期间不做持续背景动画。

## 6. 关键页面线框

评审稿包含以下可交互线框和方向切换：

- 今日时间轴：时间刻度、任务块、冲突提示、快速录入和 AI 抽屉入口。
- 专注界面：当前任务、主计时器、暂停 / 结束、环境提示和结束后的双轨反馈。
- 每日复盘：完成 / 阻塞摘要、消息输入、日记草稿和确认保存。
- 赛博日记：日期导航、心情 / 能量摘要、正文阅读和月视图入口。
- 视觉方向：A / B / C 的色彩、表面和强调色对比。

视觉评审文件：`personal-ai-visual-review.html`（当前预览服务为 `http://127.0.0.1:8765/`）。

## 7. 确认门槛

收到用户对方向 A 的确认后，才进入正式 UI 重构，顺序为：Design Token 落地 -> 应用壳 -> 今日时间轴 -> 专注 -> 复盘 -> 赛博日记 -> AI 侧边层 -> 响应式与动效验收。
